一、 創建這個網站的初衷

本網站由Ricky於2025年創辦。我通常獨自旅行，因為喜愛那種自由自在的感覺——無需遷就他人，純粹順從心意前行，想往哪裏就往哪裏。

我希望這個網站能夠一直陪伴我走下去，甚至在我四五十歲時，它依然在繼續運營。這裏將會成為我專屬的長期樹洞與回憶庫，讓我能夠一直記述着自己旅行的一點一滴、走過的足跡與當下的感動。

二、 網站名稱的由來

網站名稱「慢步·遊日記」源自我對旅行的哲學：

「慢步」：即慢慢漫步，象徵悠閒地探索世界，乘坐公共交通，從一處小站到另一處街角，細細品味沿途的風景與人情。

「遊日記」：既是我個人的旅遊日記（Diary），亦是專注日本的遊記，因為日本是我最喜愛的慢遊天堂。我主要分享日本旅遊文章，當然其他地點也會偶爾涉及。

希望透過此平台，激勵各位嘗試慢步旅行，發掘生活中的小確幸。 😊

三、 網站功能的實現工具

這個網站從2025年年中開始由零籌備、不斷寫文章，並在同年10月正式上線。整個建站過程主要運用了以下工具與技術：

開發模式：全程採用 Vibe Coding 的方式進行構建與迭代。

託管與部署：於2026年8至9月期間遷移至 GitHub 進行版本控制，並順利連結至 Cloudflare Pages 提供穩定快速的訪問。

圖片儲存：網站內所有的圖片資源均統一存放於 Cloudflare R2 物件儲存中，確保讀取高效且穩定。

站內搜尋功能：結合了 Fuse.js 與原生 JavaScript includes，實現輕量且高效能的文章關鍵字檢索體驗。
